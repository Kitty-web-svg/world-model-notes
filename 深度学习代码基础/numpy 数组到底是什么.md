就看这一个最小例子:

```python
import numpy as np
a = np.array([[1, 2, 3],
              [4, 5, 6]])
```

这就创建了一个"数组"。你可以把它想成一张表格:2 行 3 列。

- `a.shape` 会输出 `(2, 3)` —— 意思是"第一维有 2 个,第二维有 3 个"
- `a[0]` 会输出 `[1, 2, 3]` —— 取第 0 行
- `a[0, 1]` 会输出 `2` —— 取第 0 行第 1 列

就这么简单:**数组 = 数字按维度排列;`.shape` 告诉你每个维度有多少个;用方括号+逗号定位某个元素**。

之前代码里的 `dataset[0].shape` 会输出 `torch.Size([3, 64, 64])`,现在你应该能读懂这句话在说什么了:这是个 3 维的东西,第一维 3 个、第二维 64 个、第三维 64 个。
